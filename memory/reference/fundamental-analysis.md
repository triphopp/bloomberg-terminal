## 1. ข้อมูลที่ต้องหาก่อนเขียน

ใช้ตัวเลขล่าสุดเท่าที่หาได้ — ข้อมูลที่เปลี่ยนใหม่มาก่อนเสมอ

| ข้อมูล | แหล่ง (MCP tool → kind) |
|--------|-------------------------|
| งบกำไรขาดทุน / cash flow หลายปี (trend) | `get_stock_data` → `financials` |
| งบดุล: หนี้, เงินสด | `get_stock_data` → `balance-sheet` |
| margin, ROIC / ROE / ROA, leverage | `get_stock_data` → `ratios`, `quality` |
| valuation, P/E ย้อนหลัง | `get_stock_data` → `quote`, `pe-history`; ราคา → `get_price_history` |
| estimates, analyst targets, earnings date / beat-miss | `get_stock_data` → `estimates`, `analyst`, `earnings-calendar` |
| ผู้บริหาร, ผู้ถือหุ้น, ปันผล, sector | `get_stock_data` → `management`, `ownership`, `dividends`, `sector` |
| Annual report / 10-K / 20-F / 10-Q / 8-K | `get_filings(symbol, forms="10-K,20-F,10-Q,8-K")` — segment revenue, ลูกค้ารายใหญ่, risk factors อ่านจากตัวเอกสาร |
| หุ้นไทย: One Report / 56-1 | SEC Thailand API (`reference/api-endpoints.md` → SEC sections) |
| Earnings call (transcript) | `get_fiscal_data(symbol, kind="ir-events")` → `kind="transcript", event_key="q3-2026"` (ต้องมี `FISCAL_AI_API_KEY`, free trial 100 บริษัท) — ไม่มี key / ไม่อยู่ใน list → IR site ของบริษัท |

| Earnings presentation | IR site ของบริษัท |
| ข่าวและการเปลี่ยนแปลงล่าสุด | `get_news(symbols)` |
| ความสนใจของผู้บริโภค / แบรนด์ (ประกอบเท่านั้น) | `get_google_trends(keywords, geo, timeframe)` — index 0–100 เทียบ peak ในช่วงนั้น **ไม่ใช่ยอดค้นหา** · `get_trending_searches(geo)` |
| ตัวเลขงบตามที่ยื่นจริง (ใช้ตรวจ yfinance) | SEC XBRL `data.sec.gov/api/xbrl/companyfacts/CIK##########.json` (ฟรี) |

## 2. รูปแบบคำตอบ — ครบ 12 หัวข้อ

ภาษาไทยเข้าใจง่าย สำหรับมือใหม่ แต่ลึกพอให้ตัดสินใจเบื้องต้นได้ เขียนแบบภาษาคนลงทุน ไม่ใช่ภาษาราชการ

1. **บริษัททำธุรกิจอะไร** — หาเงินจากอะไร · สินค้า/บริการหลัก · รายได้แบ่งกี่ส่วน · ส่วนไหนเป็นรายได้หลักสุด · อธิบายให้คนทั่วไปเห็นภาพ
2. **ลูกค้าคือใคร** — บุคคลทั่วไป / ธุรกิจ / รัฐบาล / โรงพยาบาล / นักพัฒนา / องค์กรใหญ่ · พึ่งลูกค้ารายใหญ่ไม่กี่รายหรือกระจายดี · ลูกค้าเปลี่ยนเจ้าง่ายไหม · อะไรทำให้ลูกค้าอยู่ต่อ
3. **โมเดลรายได้และคุณภาพรายได้** — ขายครั้งเดียว vs recurring revenue · สม่ำเสมอไหม · โตจาก volume / price / subscription / ads / commission / software license / อื่น ๆ · รายได้แบบไหนคุณภาพดี และของบริษัทนี้ดีไหม
4. **ภาพรวมงบการเงินล่าสุด** — รายได้โตไหม · กำไรโตไหม · margin ดีขึ้นหรือแย่ลง · กระแสเงินสดจากการดำเนินงาน · free cash flow · หนี้เยอะไหม · เงินสดพอไหม · สรุปคร่าว ๆ ว่าแข็งแรงหรือเปราะบาง
5. **เช็คคุณภาพพื้นฐาน** (ทีละข้อ เหตุผลสั้นแต่ชัด) — รายได้โตจริงไหม · กำไรโตตามรายได้ไหม · กระแสเงินสดดีไหม · หนี้น่ากังวลไหม · margin ดีไหม · ROIC / ROE / ROA อ่านว่ายังไง · โตต่อหรือเริ่มตัน → สรุปเป็นหนึ่งใน **"พื้นฐานดี" / "ดีแต่มีจุดต้องระวัง" / "ยังไม่แข็งแรง"**
6. **จุดแข็งของธุรกิจ (moat)** — แบรนด์, network effect, switching cost, scale, cost advantage, data, technology, regulation · ของจริงหรือแค่ story
7. **Optionality / โอกาสโตในอนาคต** — สินค้าใหม่, ตลาดใหม่, ประเทศใหม่, AI / software / ecosystem / upsell / cross-sell · upside ที่ตลาดอาจยังมองไม่เต็ม · ใกล้เกิดจริงหรือยังเป็นแค่ความหวัง
8. **ความเสี่ยงที่ต้องรู้** — การแข่งขัน · ลูกค้ากระจุกตัว · กฎระเบียบ · เศรษฐกิจ · margin ลด · valuation แพงเกินไป · ความเสี่ยงที่มือใหม่มักมองข้าม
9. **ผู้บริหารและการเล่าเรื่อง** — เก่งเรื่องอะไร · พูดแล้วทำได้จริงไหม · ประวัติ execute · สิ่งที่พูดใน earnings call สอดคล้องกับตัวเลขไหม
10. **สรุปให้มือใหม่ตัดสินใจ** — ธุรกิจแบบไหนในภาษาคนทั่วไป · จุดเด่น 3 ข้อ · จุดเสี่ยง 3 ข้อ · เหมาะกับสายไหน (โต / คุณภาพ / ปันผล / turnaround / เสี่ยงสูง) · ถ้าจะศึกษาต่อควรอ่านอะไรเพิ่ม
11. **คะแนน 1–10 + เหตุผลสั้น** — ความเข้าใจง่ายของธุรกิจ · คุณภาพรายได้ · ความแข็งแรงของงบ · ความสามารถในการเติบโต · ความเสี่ยง · ความน่าสนใจโดยรวม
12. **Final Verdict** — น่าศึกษาต่อไหม · พื้นฐานดีจริงไหม · มือใหม่ควรดูอะไรเพิ่มก่อนซื้อ

## 3. เงื่อนไขบังคับ

- ห้ามตอบกว้าง ๆ หรือชมสวยหรู
- ห้ามมั่ว ห้ามคิดเองเออเอง — ทุกข้อความต้องอยู่บน fact จาก data; ระบุแหล่ง + งวดของตัวเลข (FY/quarter)
- ข้อมูลจุดไหนไม่ชัด / หาไม่ได้ → บอกตรง ๆ ว่า "ไม่ชัด" หรือ "ไม่มีข้อมูล" ห้ามเติมเอง
- ใช้ตัวเลขล่าสุด; ถ้ามีการเปลี่ยนแปลงล่าสุด เน้นข้อมูลใหม่ก่อน
- ศัพท์ยากอธิบายเป็นภาษาง่ายในวงเล็บ เช่น free cash flow (เงินสดที่เหลือจริงหลังลงทุน)
- ตัวเลขราคาใช้กฎ Number format ใน `CLAUDE.md` (ราคา ≥ 2 ตำแหน่ง)
- เป็นการวิเคราะห์เพื่อการศึกษา ไม่ใช่คำแนะนำซื้อ/ขายเฉพาะบุคคล
- **ต้องมีแหล่งอ้างอิงเสมอ:** ทุกตัวเลข/ข้อเท็จจริงต้องระบุ แหล่ง (tool/ผู้เผยแพร่ + URL หรือ filing: form, งวด, วันที่ยื่น) + วันที่ของข้อมูล — ไม่มีแหล่ง = ห้ามเขียนเป็นข้อเท็จจริง; คะแนน/มุมมอง sell-side/rating ต้องติดป้ายว่าเป็น "ความเห็น"
- **ข้อมูลฟรีก่อนเสมอ:** ลำดับ = SEC EDGAR (filings, XBRL) → IR/press release ของบริษัท → ธนาคารกลาง/FRED → Google Trends → ข่าวฟรี. แหล่งเสียเงิน (Bloomberg, research Moody's/S&P/Fitch, transcript แบบเสียเงิน) ใช้เมื่อผู้ใช้มี license และสั่งเท่านั้น; ห้าม scrape เว็บ paywall/ขัด ToS, ห้ามหลบ rate limit
- **yfinance ≠ ตัวเลขทางการ:** ตัวเลขที่บริษัทไม่ได้รายงาน (เช่น gross margin ของ Visa) ห้ามใช้; margin/กำไรให้ตรวจกับ 10-K/10-Q ก่อน
- **ระบุไตรมาส/ช่วงเวลาทุกตัวเลข** โดยเฉพาะบริษัทที่ปีบัญชีไม่ตรงปีปฏิทิน หรือรับรู้รายได้จากข้อมูลไตรมาสก่อน (เช่น service revenue ของ Visa)
- **Google Trends ใช้ประกอบเท่านั้น** — บอกความสนใจ/กระแส ไม่ใช่รายได้หรือพื้นฐาน
