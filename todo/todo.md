# สิ่งที่ต้องการสร้าง

## Contextual Analysis
Multivariate Overlay: แทนที่จะดูแค่กราฟราคาหุ้น คุณสามารถสั่ง Plot "10-Year Treasury Yield" และ "Currency Pair" ของประเทศนั้นๆ ซ้อนทับบนกราฟราคาหุ้นได้ทันที เพื่อดูว่าการที่หุ้นลงนั้นเกิดจาก Technical จริงๆ หรือเพราะ Bond Yield พุ่งสูงขึ้นจนกดดัน Valuation

Event-Driven Context: บนกราฟเดียวกัน คุณสามารถทำ EVT <GO> เพื่อแสดงจุดที่เป็นการประกาศผลประกอบการ (Earnings), การประชุมธนาคารกลาง (Fed/BOJ), หรือการจ่ายเงินปันผล ข้อมูลเหล่านี้จะถูก Map ลงบนกราฟราคาทันที ทำให้คุณเห็น "บริบท" ว่าราคานี้ตอบสนองต่อ "ข่าว" ไหน

Credit Context: นี่คือสิ่งที่เว็บทั่วไปทำไม่ได้ คุณสามารถดูสถานะของบริษัทผ่านมุมมอง Credit Default Swap (CDS) Spread ในหน้าจอเดียวกันกับราคาหุ้น หากราคาหุ้นลง แต่ CDS Spread ไม่ขยับ แสดงว่าตลาดหุ้นกู้ยังเชื่อมั่นในบริษัท (เป็นแค่ Panic ชั่วคราว) แต่ถ้าทั้งหุ้นลงและ CDS Spread พุ่งขึ้น นั่นคือสัญญาณอันตรายว่าบริษัทกำลังมีปัญหาสภาพคล่องที่ร้ายแรง

## ระบบกราฟแท่งเทียน
  ฉันไม่แน่ใจว่าถ้าเราใช้ tradingview graph api จะมีประสิทธิภาพมากน้อยแค่ไหน เพราะฉันอยากให้กราฟของเราตอบสนองเร็วและเสถียรที่สุด แต่ยังคงสามารถ Open source ในการให้ผู้ใช้สร้าง Indicator เพื่อออกแบบกลยุทธ์ตัวเองได้
  **สิ่งที่ต้องมี**
  - MACD/RSI/EMA
  - แนวรับ/แนวต้าน (อยากได้ระบบอัตโนมัติในการสร้าง) อาจใช้ volume profile เป็นตัวแทน

  ออกแบบสกิลสำหรับ Claude ให้อ่านกราฟแท่งเทียนจากเว็บดังกล่าวโดยฉันคิดว่าเราจะสร้าง mcp ให้ Cluade เข้าถึงกราฟได้จากที่นี้ แต่ยังไม่ทราบว่าจะทำยังไงให้ Claude เห็น Pattern 
  แต่เมื่อเชื่อมกับ Claude ต้องการให้สามารถ Explainable Signal — Agent และให้อธิบายเหตุผลในการเข้าซื้อ/ถือ/รอ/ขาย ไม่สนใจได้ พร้อมทั้งให้คะแนนหุ้น

  แต่ทุกครั้งจะไม่ต้องวิเคราะห์จนกว่าจะ User จะต้องการการวิเคราะห์เมื่อต้องการแล้วจึงทำ พร้อมออกแบบ Storage สำหรับเก็บบทวิเคราะห์ที่เคยวิเคราะห์ไว้อ่านครั้งถัดๆ ไปจะอ้างอิงสิ่งทีคุณเคยคิดในอดีตและความเป็นจริงว่าคุณผิดมากน้อยแค่ไหน
