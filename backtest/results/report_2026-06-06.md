## Key: How to Read This Report

- **Precision** = % of signal fires followed by a fat tail within the lookahead window
- **vs Random** = precision minus baseline (how often fat tails happen anyway × window)
- **Recall** = % of fat tails that had a preceding signal within the window
- **F1** = harmonic mean of precision × recall
- **Lead(med)** = median calendar days between signal and event
- A signal is **useful only if precision >> random AND recall is reasonable**
